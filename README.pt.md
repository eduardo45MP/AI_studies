# 🤖 AI_Studies

Um repositório dedicado a **estudo, experimentação e consolidação de conhecimento em Inteligência Artificial**.

O **AI_Studies** não é um repositório de produtos finalizados. Ele existe como um **laboratório intelectual**: um espaço para explorar ideias, testar hipóteses, documentar raciocínio e construir entendimento sólido em IA ao longo do tempo.

---

## 🎯 Propósito

Este repositório foi criado para:

* Explorar conceitos de **Machine Learning, Deep Learning e IA aplicada** com profundidade
* Transformar teoria em **experimentos executáveis**
* Registrar **decisões, hipóteses e aprendizados**, não apenas resultados
* Servir como base de conhecimento reutilizável para projetos futuros

Ele complementa projetos de produção e o portfólio pessoal, atuando como a **camada de pensamento e pesquisa**.

---

## 🧭 Princípios

O AI_Studies segue alguns princípios não negociáveis:

* **Aprendizado acima de performance**
  Um experimento é válido se gera entendimento, mesmo que o resultado seja ruim.

* **Pensamento explícito**
  Todo estudo deve deixar claro o *porquê*, o *como* e o *o que foi aprendido*.

* **Reprodutibilidade acima de polimento**
  Clareza estrutural é mais importante que otimização extrema.

* **Separação de produção**
  Quando uma ideia amadurece, ela deve sair deste repositório e ganhar vida própria.

## 📂 Estrutura Geral

A organização do repositório reflete diferentes estágios do pensamento:

```
AI_Studies/
├── articles/        # Sínteses conceituais e entendimentos consolidados
├── notebooks/      # Exploração, experimentos e raciocínio
├── datasets/       # Conjuntos de dados utilizados nos estudos
├── models/         # Modelos treinados e artefatos gerados
├── scripts/        # Utilitários e código de apoio
├── docs/           # Documentação conceitual (visão, roadmap, etc.)
├── README.md       # Este documento
└── README.pt.md    # Versão em português
```

Cada pasta responde a uma pergunta distinta:

* *O que foi explorado?* → notebooks
* *Com que dados?* → datasets
* *O que foi gerado?* → models
* *O que ficou como aprendizado?* → articles

## 🔬 Escopo de Estudo

Os temas abordados podem incluir, mas não se limitam a:

* Fundamentos de Machine Learning
* Redes neurais e Deep Learning
* Séries temporais e modelos preditivos
* Processamento de Linguagem Natural (PLN)
* Visão Computacional
* Modelos generativos
* Avaliação de modelos e métricas
* Qualidade, viés e limitações de dados

O escopo é **orientado por conceitos**, não por tendências passageiras.

# 🤖 AI_Studies

A repository dedicated to **study, experimentation, and consolidation of knowledge in Artificial Intelligence**.

**AI_Studies** is not a collection of finished products. It exists as an **intellectual laboratory** — a space to explore ideas, test hypotheses, document reasoning, and build durable understanding in AI over time.

---

## 🎯 Purpose

This repository was created to:

* Explore **Machine Learning, Deep Learning, and applied AI** concepts in depth
* Translate theory into **executable experiments**
* Record **decisions, assumptions, and learnings**, not only outcomes
* Serve as a reusable knowledge base for future projects and systems

It complements production projects and the personal portfolio by acting as the **thinking and research layer**.

---

## 🧭 Principles

AI_Studies follows a set of non-negotiable principles:

* **Learning over performance**
  An experiment is successful if it increases understanding, even when results are poor.

* **Explicit thinking**
  Every study should clearly state *why it exists*, *how it was conducted*, and *what was learned*.

* **Reproducibility over polish**
  Structural clarity matters more than extreme optimisation.

* **Separation from production**
  When an idea matures, it should leave this repository and evolve into its own project.

---

## 📂 Repository Structure

The organisation of the repository mirrors different stages of thinking:

```
AI_Studies/
├── articles/        # Conceptual syntheses and consolidated understanding
├── notebooks/      # Exploration, experiments, and reasoning
├── datasets/       # Datasets used in studies
├── models/         # Trained models and generated artefacts
├── scripts/        # Utilities and supporting code
├── docs/           # Conceptual documentation (vision, roadmap, etc.)
├── README.md       # This document
└── README.pt.md    # Portuguese version
```

Each folder answers a distinct cognitive question:

* *What was explored?* → notebooks
* *With which data?* → datasets
* *What was produced?* → models
* *What remained as knowledge?* → articles

## 🔬 Scope of Study

Topics may include, but are not limited to:

* Machine Learning fundamentals
* Neural networks and Deep Learning
* Time series and predictive modelling
* Natural Language Processing (NLP)
* Computer Vision
* Generative models
* Model evaluation and metrics
* Data quality, bias, and limitations

The scope is **concept-driven**, not trend-driven.

---

## 🌐 Relationship to the Portfolio

AI_Studies does not exist to impress — it exists to **think clearly**.

While the portfolio answers:

> *What can I build?*

This repository answers:

> *How do I think about AI?*

Only mature, well-formed insights should surface in the portfolio.
Everything else stays here — raw, honest, and traceable.

---

## 🚀 Expected Evolution

Over time, this repository should become:

* A personal map of AI understanding
* A traceable history of idea evolution
* A solid foundation for research-driven products and systems

The focus is not mastery of specific tools, but **development of technical judgement and abstraction in AI systems**.
